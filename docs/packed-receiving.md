# Packed receiving and worker-stage diagnostics

The native renderer still computes the complete field and emits exactly the same AFL1 bytes. Alien's window validates every packet and Unicode cell before passing immutable bytes through the existing Living Buffer. Cells remain available through immutable lazy row views. GPU texture preparation reads packed code points/RGB directly into one renderer-owned staging array, retaining the original atlas ordering, overflow behavior and colour values. Geometry changes replace the staging array; retained messages remain independent.

The accepted MirrorPool and its provenance are unchanged. Its one elastic pool continues receiving and verifying the native bytes. Tighter blanket layout remains a separate engine experiment; this update targets the measured host allocation path and adds evidence about remaining CPU cost.

Use the normal **Save report** button under the same continuing world. New reports include worker stages (whole frame, layers/ripples, math study, vector searches, event-bus dispatch, encoding/sending, learning and neural entry points), window receive/validate and texture stages, receiver exchange timing, and staging allocation/reuse counts. Learning input deferrals are split into load, sleep, dream and closed reasons, with current state flags.

These are bounded diagnostic measurements, with no per-cell timers or raw content. CPU spans use the currently executing thread; other threads are outside those spans. Different nested stages overlap, so totals cannot be added together as disjoint costs. Each profile has a current-process token and measured elapsed denominator. Reopening keeps the same Alien world but starts new process profiles; the analyser labels the latest retained profile separately from cumulative world diagnostics. Receiver CPU is Python receiver-thread work; its wall interval includes Node/IPC wait. Helper CPU stays in the existing process-role samples.

Matched synthetic benchmarks measure decode plus texture preparation only, against the ordinary validated decoder and original texture builder with identical bytes. They do not establish whole-app CPU, FPS or long-run stability gains. The owner's next live report will show how this path and the worker stages behave in practice. Native tick, visual geometry/cadence, model prompts, provider settings, quota, cache and original Alien are preserved.

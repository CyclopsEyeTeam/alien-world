# Written alphabet inside Alien's rift hive

The mathematical profile runs inside the existing hive. The earlier decoding
header/dialog has been removed. No button, manual text entry or audio is needed.

Exact admitted incoming text starts one written study; final public owned
`thought` and `self_continuation` events start the other. Private thoughts,
dream/replayed material and derived learning conclusions are excluded from these
entrances. Incoming sources and self-computation remain distinguishable.

Each accepted study retains original text, actual source stamp/provenance and
ordered letter, space and rejected-symbol events inside the existing binary cache.
ASCII letters use `az-log-220-880-v1`, index `i=0..25`, exact exponent `[2*i,25]`
and scalar `220*2^(2*i/25)`: A is exactly220, Z exactly880. Source case, repeated
letters and every space remain intact. Digits, punctuation and other glyphs are
explicitly rejected for the AZ mapping, retained verbatim, and never substituted.
The strict standalone codec still rejects unsupported complete inputs.

After the study's real archive ACK, actual native ticks advance the two channels
fairly, at most one symbol per new tick. There is no millisecond clock or timer.
Original receipt time and later study time are separate; this computation does
not pretend to receive the text again. Spaces and rejected glyphs publish typed
boundaries without numeric values. Letters publish existing `numeric_pattern`
events containing written expressions and validated service-owned evidence.

Existing numeric consumers receive the computation. The learning adaptor uses
`alphabet_position=i/25` and the same `log_scale` measurement as native maths,
computed from `log10(value)`. Incoming/own alphabetical streams can form reciprocal
rifts with each other and compatible native mathematical streams. The ordinary
learner, archive ACK, active-peer, mirror/approbation and owned-language gates then
control any written conclusion/residue. There is no new root truth, semantic
verification, external observation, vocabulary insertion or readiness shortcut.

Studies pause under native sleep/dream and stop with their owner. Under high native load they use a bounded stride of at least four actual ticks per symbol; only validated alphabet learning/yields receive that reduced budget, with at least16native ticks between written yields. Other learning load deferrals stay unchanged. Incomplete
studies are cancelled on closure; retained history stays inert and never replays
as fresh proof. The canonical world, segment and tick continue as before. Working
queues are bounded to8 jobs,4 per channel,4096UTF-8bytes per study and16384queued
bytes; refusal, rejection and archive-failure counts remain explicit. Original
material continues on its established path even when study capacity is refused.

Use the existing **Save report** control to inspect scalar incoming/own counts,
studied letters, spaces, rejected symbols, pending studies and temporal crossings.
Original writing, symbol receipts and private rift measurements are excluded from
those reports. These counts describe execution, not general understanding.

Developer checks use the shared contained runner, HDD TMPDIR and
`PYTHONPATH="$PWD/app"` and `MALLOC_ARENA_MAX=2`: `python3 -B checks.py` includes the exact26mapping codec,
ordered study/lifecycle/ACK tests, actual installed-bus/rift tests, input admission,
scalar reporting, native geometry and all previous project checks.

The complete suite retains its512MiB address-space limit. Bounding allocator arenas
keeps cumulative validation reservations within that limit; the normal application
launcher and its limits are unchanged.

# Temporal flow across active streams

Alien can cross between ongoing measured patterns that share named channels. Each receipt keeps its original source, source epoch, world, segment and native tick. Reciprocal rifts allow movement in both directions; previous/next paths retain actual observed order. Different segments/worlds remain an unknown interval. No extra world clock exists.

A graph holds at most64 receipts,192 directed links and8 active source profiles. Each accepted input compares the most recent receipts of other active sources, links at most two compatible peers and keeps at most two hops per route. A64-native-tick window, source/mask changes, sleep and Stop close live crossings. Walking a path never trains or creates input. The earlier forecast-fork experiment is preserved as an experiment and is not included here.

The yielding adaptor chooses bounded route context alongside its own mathematical conclusion. Both enter the existing binary cache before publication. A real archive acknowledgement and current source/peer checks are required for a temporal_rift event. The existing unauthority residue receives a compact ↔ crossing mark and typed private context. It still follows mirror/approbation rules. Route affinity and numerical diversity may influence selection and owned-register variation; they add no vocabulary, readiness, support or root truth.

History carries forward under learning.temporal.flow/v1 in the single content cache. Restored receipts are inactive, without live source connections or clock resume. Invalid optional graph history is rejected independently of existing learning recipes. There are no extra workers or model calls.

Use the existing Save run report button for a long run. Its latest retained scalar learning sample includes temporal receipts, active streams, links, durable routes and crossing counts. Private route graphs and measurements remain inside the cache. A zero route count means no still-current compatible crossing was durably published during that sample; it is not a fault by itself.

The release is selected for the next fresh launch. Promotion leaves existing windows, original Alien, older releases, credentials, quota and owner data alone.
